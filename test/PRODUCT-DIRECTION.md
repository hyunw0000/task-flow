# 제품 방향
## 아이디어
할 일을 카드로 등록하고, 카드마다 지금 어떤 상태인지 한눈에 보는 Task 관리 웹 앱을 만들고 싶다.
## 고정 조건 (바꾸지 않는다)
- 웹 앱이다. 브라우저에서 쓴다.
- 제품 안에 AI 기능은 넣지 않는다. AI 는 만드는 과정에서만 쓴다.
- 기술 표준 경로: 화면 React · Vite, API FastAPI, 저장소 SQLite.
- 각자 자기 컴퓨터에서 실행한다. 배포는 이번 범위가 아니다.
- 결제 · 외부 알림은 만들지 않는다.
## 정한 것 (묻고 답하며 정함)
### 첫 사용자
- 혼자 일을 관리하는 개인이다.
- 로그인 · 팀 기능은 첫 버전에 넣지 않는다.
### 카드 정보
- 제목: 꼭 필요하다.
- 설명
- 상태
### 상태의 종류
- 할 일 · 진행 중 · 완료, 세 가지다.
- 상태는 사용자가 직접 고른다. 자동으로 바뀌지 않는다.
### 첫 버전 기능
- 카드 등록
- 상태 변경
- 상태별 보기
- 수정과 삭제
### 나중에 한다
- 마감일
## 열린 질문 (아직 정하지 않음)
- 설명은 비워 두어도 되는가?
- 새 카드를 등록할 때 처음 상태는 무엇인가? 늘 "할 일"인가, 등록할 때 사용자가 고르는가?
- 상태를 순서대로만 바꿀 수 있는가, 세 상태 가운데 아무 곳으로나 바로 옮길 수 있는가?
- 화면에서 상태를 바꾸는 방법은 무엇인가? (예: 드래그, 버튼, 드롭다운)
- "상태별 보기"는 어떤 모양인가? (예: 상태별 칸이 나란히 있는 보드, 상태로 거르는 목록)
- 같은 상태 안에서 카드는 어떤 순서로 놓이는가? 사용자가 순서를 바꿀 수 있어야 하는가?
- 삭제할 때 한 번 더 확인을 받는가? 지운 카드를 되살릴 수 있어야 하는가?
- 제목 · 설명에 길이 제한이 있는가?
