# 화면 명세

- 출처: [PRD.md](PRD.md), [USER-WORKFLOW.md](USER-WORKFLOW.md), [ARCHITECTURE.md](ARCHITECTURE.md)
- 휴대폰 세로 화면을 기준으로 한다. (A-02) 색·글꼴 같은 모양은 정하지 않았다. 아래는 **무엇을 보여 주고 무엇을 누르는가**만 적는다.

## 1. 화면 목록

| ID | 화면 | 경로 | 언제 보이나 |
| --- | --- | --- | --- |
| S-01 | 모임 만들기 | `/` | 처음 열 때 |
| S-02 | 참여 | `/m/{모임 id}` (아직 참가자가 아닐 때) | 링크로 들어왔고 이 브라우저에 참가 정보가 없을 때 |
| S-03 | 모임 방 | `/m/{모임 id}` (참가자일 때) | 참가한 뒤 |
| S-04 | 안내 | `/m/{모임 id}` | 만료·종료·잠김·가득 참 |

모임 방(S-03)은 위쪽 지도와 아래쪽 탭 세 개로 이루어진다. 탭은 **추천 · 후보 · 사람**이다.

## 2. S-01 모임 만들기

- 입력: 모임 이름, 내 이름, 상황(점심 · 저녁 · 2차) 중 하나.
- 누르는 것: 「모임 만들기」.
- 검증: 이름은 비어 있으면 안 된다. (BR-01) 오류는 입력칸 옆에 보인다.
- 성공하면 S-03으로 이동한다.

## 3. S-02 참여

- 보여 주는 것: 모임 이름, 상황, 현재 참가 인원.
- 입력: 내 이름.
- 누르는 것: 「참여하기」.
- 위치 동의는 S-03에 들어간 직후 별도 안내로 받는다. 이름 입력과 동의를 한 번에 묶지 않는다. (R-002)

## 4. S-03 모임 방

### 4-1. 지도 (항상 보임)

| 요소 | 내용 | 요구사항 |
| --- | --- | --- |
| 참가자 점 | 이름 표시. 내 점은 다르게 보인다. 5분 넘게 갱신이 없으면 흐리게 + "n분 전" | R-003 |
| 기준 지점 | 별 표시와 이름(역 이름 등) | R-005 |
| 각자의 이동시간 | 기준 지점을 누르면 참가자별 이동시간·거리가 보인다 | R-008 |
| 추천 장소 | 추천 탭에서 고른 장소가 핀으로 보이고, 누르면 참가자별 거리가 보인다 | R-008 |
| 후보 장소 | 후보 탭의 장소는 다른 핀으로 보인다 | R-009 |

### 4-2. 위치 공유 바 (지도 위, 항상 보임)

- 상태 표시: 「공유 중」 / 「꺼짐」.
- 누르는 것: 켜기·끄기 스위치. 처음 켤 때 동의 안내를 보인다. (PRD 8장)
- 안내 문구: "이 화면을 켜 두는 동안만 위치가 공유됩니다." (A-05)
- 켜기 오류: 브라우저 권한이 막혀 있으면 허용 방법을 안내한다.

### 4-3. 추천 탭

- 위쪽: 상황 프리셋 세 개(점심 · 저녁 · 2차). 모임의 상황이 처음 선택되어 있다. (R-007)
- 카테고리 칩: 밥집 · 술집 · 카페. 프리셋에 따라 기본 선택이 바뀐다. (BR-12)
- 목록 항목: 이름, 카테고리, 평점(없으면 "평점 없음"), 영업 중 여부, 기준 지점에서 거리, 참가자 중 가장 먼 사람까지 거리.
- 누르는 것: 항목(지도에 핀 표시), 「후보로 올리기」.
- 상태: 불러오는 중, 결과 없음, 불러오기 실패(다시 시도).
- 기준 지점이 아직 없으면 "한 사람 더 위치를 공유하면 추천을 볼 수 있어요"를 보인다. (BR-10)

### 4-4. 후보 탭

- 목록 항목: 장소 이름, 올린 사람, 득표 수, 내가 투표했는지.
- 누르는 것: 「투표」 / 「투표 취소」, 올린 사람 또는 모임장은 「후보 삭제」.
- 모임장에게만 「확정」 버튼이 보인다. 누르면 확인 질문을 한 번 보인다.
- 확정되면 탭 위에 확정 장소 카드가 보이고 투표·후보 조작은 사라진다.

### 4-5. 사람 탭

- 목록: 참가자 이름, 모임장 표시, 공유 중 여부, 마지막 갱신 시각.
- 링크 복사 버튼. (R-010)
- 모임장에게만 보이는 것: 참가자 「내보내기」, 「모임 잠금」 스위치, 「모임 끝내기」. 끝내기는 확인 질문을 한 번 보인다.

## 5. S-04 안내

| 상황 | 문구 | 누르는 것 |
| --- | --- | --- |
| 만료 | 만료된 모임입니다 | 「새 모임 만들기」 |
| 종료 | 모임이 끝났습니다 | 「새 모임 만들기」 |
| 잠김 | 모임장이 모임을 잠갔습니다 | 없음 |
| 가득 참 | 모임이 가득 찼습니다 (최대 6명) | 없음 |
| 내보내짐 | 이 모임에서 나가게 되었습니다 | 「새 모임 만들기」 |

## 6. 공통 상태

- 실시간 연결이 끊기면 화면 위에 "연결이 끊겼습니다. 다시 연결 중…"을 보이고 자동으로 다시 붙는다. (ARCHITECTURE 5장)
- 모든 오류는 한국어 문장으로 보인다. 서버가 준 `detail`을 그대로 보이지 않는다.
