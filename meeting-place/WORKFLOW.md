# 진행 순서

열 단계를 차례로 밟는다. 각 단계의 산출물은 GitHub에 남긴다.

| # | 단계 | 내용 | 남기는 곳 | 상태 |
| --- | --- | --- | --- | --- |
| 01 | 규칙 | [AGENTS.md](AGENTS.md) | 저장소 · 첫 커밋 | 초안 작성 |
| 02 | PRD | 목표 · 비목표 · 요구사항 ID ([PRD.md](PRD.md)) | `docs:` 커밋 | 초안 작성 |
| 03 | 명확화 | 결정 사항 · 열린 질문 | PRD 개정 커밋 | 대기 |
| 04 | 계획 | 화면 · 데이터 · API | 설계 문서 커밋 | 대기 |
| 05 | 분해 | 마일스톤 · 작업 목록 | 이슈 등록 | 대기 |
| 06 | 구현 | 계획 먼저, 그다음 코드 | `feature/` 브랜치 | 대기 |
| 07 | 검증 | 테스트 · 직접 확인 | 확인 기록 | 대기 |
| 08 | 제출 | 커밋 · PR 설명 | Pull Request | 대기 |
| 09 | 병합 | 리뷰 · 기준선 | 병합 · 태그 | 대기 |
| 10 | 반복 | 버그 · 새 아이디어 | `fix/` 브랜치 · Backlog | 대기 |

## 단계 사이 규칙

- 앞 단계가 끝나기 전에 다음 단계로 넘어가지 않는다. 03의 열린 질문이 남아 있으면 04에서 해당 부분을 확정하지 않는다.
- 06 이후 새 아이디어가 나오면 바로 만들지 않고 10의 Backlog에 적는다.
