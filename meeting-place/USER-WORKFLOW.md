# 사용자 워크플로: 모임 만들기부터 장소 확정까지

- 출처: [PRD.md](PRD.md), [DECISIONS.md](DECISIONS.md), [ARCHITECTURE.md](ARCHITECTURE.md)
- 정하지 않은 것은 「결정 필요 (Q-xx)」로 표시한다. D-xxx는 임시로 따르는 잠정 결정이다.

## 1. 사용자와 시작·종료

- **모임장**: 모임을 만든 사람. 모임당 한 명이다.
- **참가자**: 링크로 들어온 사람. 모임장도 참가자다. 모임당 최대 6명. (A-01)
- 시작: 모임장이 첫 화면에서 모임을 만든다.
- 종료: 모임장이 장소를 **확정**했거나, 모임이 **만료**되었거나(D-009), 모임장이 모임을 **끝냈다**.

## 2. 주 흐름

| 단계 | 누가 | 행동 | 결과 | 요구사항 |
| --- | --- | --- | --- | --- |
| 1 | 모임장 | 모임 이름과 상황을 고르고 만든다. 자기 이름도 입력한다. | 모임이 생기고 모임 방으로 이동한다. | R-001 |
| 2 | 모임장 | 링크를 복사해 채팅방에 붙여 넣는다. | 링크가 퍼진다. | R-010 |
| 3 | 참가자 | 링크를 열고 이름을 입력한다. | 모임에 참가자로 등록된다. | R-002 |
| 4 | 참가자 | 위치 공유에 동의한다. 브라우저 권한도 허용한다. | 지도에 내 위치가 보인다. | R-002, R-003 |
| 5 | 모두 | 서로의 위치가 지도에 실시간으로 움직인다. | 지도에 참가자 점이 보인다. | R-003 |
| 6 | 시스템 | 위치가 2곳 이상 모이면 기준 지점을 계산한다. 위치가 크게 바뀌면 다시 계산한다. | 지도에 기준 지점과 각자의 이동시간이 보인다. | R-005, R-008 |
| 7 | 모두 | 추천 탭에서 기준 지점 주변 밥집·술집을 본다. 카테고리와 상황 프리셋을 바꾼다. | 점수순 목록이 보인다. | R-006, R-007 |
| 8 | 모두 | 마음에 드는 장소를 후보로 올린다. | 후보 목록에 추가된다. | R-009 |
| 9 | 모두 | 후보 하나에 투표한다. 다시 눌러 바꿀 수 있다. | 득표 수가 모두에게 보인다. | R-009 |
| 10 | 모임장 | 득표를 보고 하나를 확정한다. | 모임이 확정 상태가 되고 모두에게 결과가 보인다. | R-009 |
| 11 | 시스템 | 확정과 함께 위치 공유를 멈추고 위치 데이터를 지운다. | 지도에 사람 점이 사라진다. | PRD 8장, D-009 |

## 3. 다른 흐름

| 상황 | 흐름 |
| --- | --- |
| 브라우저 위치 권한을 거부했다 | 지도에 내 위치가 없다는 안내를 보인다. 모임 방은 볼 수 있지만 계산에는 빠진다. 직접 입력은 1차에 없다. (Q-13) |
| 위치 공유를 중간에 끈다 | 서버의 마지막 위치를 지운다. 다른 사람의 지도에서 사라지고 기준 지점이 다시 계산된다. (R-004) |
| 화면을 끄거나 다른 앱으로 간다 | 위치 전송이 멈춘다. 다른 사람 지도에 "n분 전 위치"로 흐리게 보이고, 5분이 넘으면 계산에서 빠진다. (A-05, BR-06) |
| 7번째 사람이 링크를 연다 | "모임이 가득 찼습니다"를 보인다. (BR-02) |
| 링크가 엉뚱한 사람에게 갔다 | 모임장이 참가자를 내보내거나 모임을 잠근다. 내보낸 사람은 다시 들어올 수 없다. (D-013, Q-11) |
| 위치가 한 곳뿐이다 | 기준 지점을 계산하지 않고 "한 사람 더 필요합니다"를 보인다. (BR-10) |
| 투표가 동률이다 | 모임장이 동률 후보 중 하나를 확정한다. (D-010, Q-06) |
| 모임장이 모임을 끝낸다 | 모든 데이터가 지워진다. 참가자 화면에는 "모임이 끝났습니다"를 보인다. |
| 만료된 모임 링크를 연다 | "만료된 모임입니다"를 보인다. |
| 추천 목록을 불러오지 못했다 | 외부 API 오류 안내와 다시 시도 버튼을 보인다. 지도와 투표는 계속 쓸 수 있다. |
| 같은 브라우저로 다시 들어온다 | 저장된 참가 정보로 이름 입력 없이 복귀한다. (D-004) |

## 4. 흐름 요약

```
모임 만들기 → 링크 공유 → 참가·동의 → 실시간 위치 → 기준 지점 → 추천 탐색 → 후보 올리기 → 투표 → 확정
```
